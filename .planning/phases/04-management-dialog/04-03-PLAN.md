  <how-to-verify>
**Step 0 — Boot dev environment:**
1. In one terminal: `python main.py --dev`  (FastAPI on :8000, hot reload)
2. In another terminal: `cd frontend && npm run dev`  (Vite dev server)
3. Open the Vite URL printed by step 2 (typically http://localhost:5173) in a desktop browser.

**Step 1 — DIALOG-01 (open from menu):**
- Click the **Edit** menu in the top menu bar.
- Verify a "World Sets…" item appears (after "Manage Tilesets…").
- Click "World Sets…".
- Expected: A modal dialog appears with title "World Sets", a section labeled "World Sets", a list (or "No world sets found." empty state), a name input + Create button, and a Close button.

**Step 2 — Backdrop dismiss + inner-click preservation (Pitfall 2):**
- Click anywhere on the **dark backdrop** (outside the dialog box). Expected: dialog closes.
- Re-open via Edit > World Sets…
- Click on the dialog **title text** ("World Sets"). Expected: dialog stays open.
- Click on the dialog **input field**. Expected: dialog stays open and input is focused.

**Step 3 — Create a world set:**
- Type `smoke-test` into the name input.
- Click "Create".
- Expected: Dialog transitions to nodes view with title "World Set: smoke-test" and message "No maps added yet."
- Click "Back". Expected: returns to list view; "smoke-test" is in the list.

**Step 4 — DIALOG-05 — scale picker conditional rendering:**
- Click "smoke-test" in the list. Dialog enters nodes view.
- Click "Add map node". Dialog enters configure view (title "Add Map Node").
- Open the **Map** select dropdown.
- Pick a map that you know **has no `feetPerUnit`** (e.g. an old map from `maps/`).
  - Tip: if no such map exists, open the JSON of a map in `maps/` and delete the `"feetPerUnit"` field (and the `"scale"` field), then save.
- Expected: A new `.dialog-row` labeled "Scale" appears immediately BELOW the Map row and ABOVE the Parent row.
- Switch to a **different map** that you know HAS `feetPerUnit` (or has a recognised `scale` ID).
- Expected: The Scale row disappears.

**Step 5 — Parent/anchor conditional rendering:**
- With any map selected, set Parent to "None (root)". Expected: no Anchor col / Anchor row inputs visible.
- Set Parent to an existing node (if one is in the world set). Expected: Anchor col + Anchor row inputs appear.

**Step 6 — Cleanup:**
- Click "Back" to return to nodes view, then "Back" again for list view.
- Find "smoke-test" in the list, click "Delete".
- Expected: An inline `.dialog-warn` block appears with "Delete 'smoke-test'? This cannot be undone." and Cancel + "Yes, delete" buttons.
- Click "Yes, delete". Expected: row disappears from the list.
- Click "Close" to dismiss the dialog.

**Step 7 — Production build smoke (sanity):**
- Stop the dev servers.
- Run `cd frontend && npm run build` — confirm exit 0.
- Run `python main.py` — confirm the production server starts.
- Open http://localhost:8000 in browser — confirm the app loads with the new menu item.
