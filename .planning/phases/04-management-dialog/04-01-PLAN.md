**Handlers (exact behavior per D-01, D-02, D-03, D-04 + UI-SPEC View 1):**

1. `handleSelect(name: string)` — calls `await setActiveWorldSet(name)`, then `setView('nodes')`. Wrap in try/catch, set error on failure.

2. `handleCreate()`:
   - Trim newName. If empty, `setError('Name is required')` and return.
   - If `worldSets.includes(name)`, `setError('A world set with that name already exists')` and return.
   - `setLoading(true); setError('')`.
   - Build `const ws: WorldSet = { name, version: WORLD_SET_VERSION, nodes: [] }`.
   - `await apiSaveWorldSet(name, ws)` — POST to server.
   - Refresh: `const updated = await listWorldSets(); setWorldSets(updated);`.
   - `await setActiveWorldSet(name)` — store loads from server.
   - `setNewName('')`.
   - `setView('nodes')`.
   - try/catch sets `setError(String(e))`. Always set loading false in finally.

3. `handleDeleteClick(name: string)` — sets `confirmDelete = name` (does NOT delete yet, shows confirm prompt).

4. `handleConfirmDelete()`:
   - If `confirmDelete === null` return.
   - `setLoading(true); setError('')`.
   - `await deleteWorldSet(confirmDelete)`.
   - `const updated = await listWorldSets(); setWorldSets(updated);`.
   - If `confirmDelete === activeWorldSetName`, `await setActiveWorldSet(null)`.
   - `setConfirmDelete(null)`.
   - try/catch + finally as above.

5. `handleCancelDelete()` — `setConfirmDelete(null)`.
