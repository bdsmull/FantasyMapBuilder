<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Smoke test — canvas footprints, hover, click, breadcrumb</name>
  <what-built>
    Full Phase 6 canvas integration:
    - footprintOverlay.ts renders child footprint outlines on the map canvas
    - MapCanvas.tsx: hover highlight, tooltip, click navigation, overlap picker, touch two-tap
    - StatusBar.tsx: parent breadcrumb with click navigation
  </what-built>
  <how-to-verify>
    **Prerequisites:** Start both dev servers (python main.py --dev + npm run dev).
    You will need at least one world set with 2-3 map nodes to test all scenarios.
    If no world set exists, create one via World Sets dialog (Edit menu → World Sets…).

    **Test 1 — CANVAS-01/02: Footprint outlines appear**
    1. Open a map that has child maps in the active world set.
    2. Confirm: dashed blue outline(s) appear on the canvas for each child map's anchor location.
    3. Confirm: each outline has the child map's name as a label centered within it.

    **Test 2 — CANVAS-03: Placeholder footprint for no-feetPerUnit child**
    1. Add a child node for a map that has no `feetPerUnit` set (no scale assigned).
    2. Open the parent map.
    3. Confirm: a 1×1 amber/yellow dashed footprint appears at the anchor with a `?` label.
    4. Confirm: it is visually distinct from the blue normal footprints.

    **Test 3 — CANVAS-04: Hover tooltip (desktop only)**
    1. Hover the mouse over a footprint outline.
    2. Confirm: the footprint's fill and border brightens (hovered state).
    3. Confirm: the mouse cursor changes to a pointer (hand icon).
    4. Confirm: a tooltip appears near the cursor showing the child map name and a second line.
    5. Move mouse off the footprint — confirm tooltip disappears and footprint returns to normal.

    **Test 4 — CANVAS-05: Click to navigate (desktop)**
    1. Click a footprint — confirm navigation to the child map occurs.
    2. Make a tile edit (paint something), then click a footprint.
    3. Confirm: "Unsaved Changes" dialog appears with Save / Discard / Cancel buttons.
    4. Click Cancel — confirm you stay on the current map, no navigation.
    5. Make another edit, click a footprint, click Discard — confirm navigation without saving.
    6. Make another edit, click a footprint, click Save & Navigate — confirm map saved and navigation occurs.

    **Test 5 — CANVAS-05: Overlap picker (desktop)**
    1. If you have overlapping footprints (two child nodes at the same anchor): click the overlapping area.
    2. Confirm: a picker popup appears listing both children by name.
    3. Click a name in the picker — confirm navigation to that child.
    4. Click outside the picker — confirm it dismisses without navigating.
    5. Press Escape while picker is open — confirm it dismisses.

    **Test 6 — CANVAS-06: Status bar breadcrumb**
    1. Navigate to a child map that has a parent in the world set.
    2. Confirm: status bar shows `↑ ParentMapName > CurrentMapName` before the map name.
    3. Confirm: the parent name is blue/accent colored and shows a pointer cursor.
    4. Click the parent name — confirm navigation to the parent map.
    5. Navigate to a root map (no parent) — confirm breadcrumb is absent.
    6. Deactivate the world set (if possible) — confirm breadcrumb disappears.

    **Test 7 — No world set active (regression)**
    1. With no world set active, open any map.
    2. Confirm: canvas shows no footprint overlays.
    3. Confirm: all map editing tools still work normally (paint, erase, fill).
    4. Confirm: status bar shows no breadcrumb.
  </how-to-verify>
  <resume-signal>
    Type "approved" if all 7 tests pass.
    Or describe any failures and which test they occurred in.
  </resume-signal>
