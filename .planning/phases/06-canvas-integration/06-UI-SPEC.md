## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, toggle padding |
| sm | 8px | Compact element spacing, breadcrumb internal padding |
| md | 16px | Default element spacing, gap between breadcrumb and map name in status bar |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Status bar height is 24px (existing fixed value — do not change)
- Touch targets (footprint picker items, breadcrumb button): minimum 44px height on touch viewports (iPad ≤1024px)
- Footprint label horizontal padding: 4px on each side (spacing contract value). No vertical padding is declared — vertical centering is achieved by `ctx.textBaseline = 'middle'` in the canvas renderer (implementation detail, not a spacing contract value).

> Source: `App.css` `.status-bar { height: 24px }`, `.toolbar { min-height: 44px }` — 44px touch target minimum is an established project pattern.

## Interaction Contracts

### Footprint Rendering (CANVAS-01, CANVAS-02, CANVAS-03)

- Footprints are drawn every render frame as the final canvas pass after `renderTileMap` / `renderHexMap`
- `renderFootprintOverlay(ctx, children, currentMapData, view, hoveredMapName)` receives pre-computed children array from `childrenOf(currentMapName)` in `worldSetStore`
- `footprintAtPoint(screenX, screenY, children, currentMapData, view)` returns `string[]` — zero, one, or many matching child map names
- Coordinate conversion: tile → screen uses `(col * tileWidth + pan.x) * zoom` for square maps; `hexRenderer`'s `hexToPixel` equivalent for hex maps

### Hover (CANVAS-04) — Desktop

- `onPointerMove`: call `footprintAtPoint()`; if result differs from current `hoveredFootprint` state, update state + call `requestAnimationFrame(render)`
- Cursor: set `canvas.style.cursor = 'pointer'` when hovering any footprint; reset to `'crosshair'` (or `'default'` when no tool active) otherwise
- Tooltip: position `.footprint-tooltip` at `(event.clientX + 12, event.clientY - 8)` — offset right and up to avoid occluding the cursor; clamp to viewport so tooltip never overflows right or bottom edge

### Touch Two-Tap Model (CANVAS-04) — iPad

- First `pointerdown` (touch) on a footprint: set `touchedFootprint` to that map name; show `.footprint-tooltip`; do NOT navigate
- Second `pointerdown` on the same footprint: navigate (call `navigateToMap`)
- `pointerdown` anywhere else: clear `touchedFootprint`; hide tooltip
- For overlapping footprints (touch): first tap opens `.footprint-picker` popup; tapping a picker item navigates

### Click Navigation (CANVAS-05) — Desktop

- `onPointerDown` with `pointerType === 'mouse'`: call `footprintAtPoint()`
  - 0 hits: fall through to tool dispatch (normal editing)
  - 1 hit: call `navigateToMap(childMapName)` — dirty-map guard modal applies
  - 2+ hits: show `.footprint-picker` at click position; no tool dispatch

### Overlap Picker

- Position: `{ left: event.clientX, top: event.clientY }` absolute in viewport
- Dismiss on: click/tap outside (document `pointerdown` listener, removed on dismiss), or `Escape` key
- Max items displayed: all overlapping children (no pagination — overlap count is bounded by world set size)
- Item order: alphabetical by map name
- Item copy: map name only (no scale in picker — scale is in the tooltip, not the picker)

### Parent Breadcrumb (CANVAS-06) — Status Bar

- Layout: `[↑ ParentName > CurrentMapName]` — rendered left of the existing `.status-name` span
- The `↑` arrow and `>` separator are non-interactive decorators
- Only `ParentName` is a clickable `<button>` (`.status-breadcrumb-link`); clicking calls `navigateToMap(parentName)`
- On narrow viewports (≤1024px): `ParentName` truncates with `text-overflow: ellipsis` at `max-width: 80px`
- Dirty-map guard: same Save / Discard / Cancel modal used by hierarchy panel — no new modal needed

### Dirty-Map Guard

- Reuses the existing modal from Phase 5 (no new UI)
- Applies to: footprint click navigation, overlap picker item click, breadcrumb click
- Not applicable to hover or tooltip display

## States and Transitions

| State | Canvas | Status Bar | Picker | Tooltip |
|-------|--------|------------|--------|---------|
| No world set active | No overlay | No breadcrumb | — | — |
| World set active, current map has no children | No overlay | Breadcrumb if parent exists | — | — |
| World set active, current map has children | Footprints rendered | Breadcrumb if parent exists | — | — |
| Mouse over footprint (desktop) | Hovered footprint highlighted; cursor=pointer | Unchanged | — | Visible |
| Mouse leaves footprint | Normal state restored; cursor reset | Unchanged | — | Hidden |
| Click 1 footprint (desktop) | Navigate (dirty guard) | Updates after nav | — | Hidden |
| Click overlapping footprints (desktop) | No highlight | Unchanged | Visible | — |
| Touch 1 footprint, first tap (iPad) | Unchanged | Unchanged | — | Visible |
| Touch 1 footprint, second tap (iPad) | Navigate (dirty guard) | Updates after nav | — | Hidden |
| Touch overlapping footprints (iPad) | Unchanged | Unchanged | Visible | — |
