**computeScreenRect helper (not exported):**
Given a Footprint (tile-space) and map/view, return the screen-space rectangle.
Use `tileToScreen(fp.colMin, fp.rowMin, view, map.tilewidth, map.tileheight)` for
the top-left corner. Width = `(fp.colMax - fp.colMin + 1) * map.tilewidth * view.zoom`.
Height = `(fp.rowMax - fp.rowMin + 1) * map.tileheight * view.zoom`.

**renderFootprintOverlay — main export:**
```typescript
export function renderFootprintOverlay(
  ctx: CanvasRenderingContext2D,
  children: WorldSetNode[],
  parentMap: TmjMap,
  view: ViewState,
  hoveredMapName: string | null,
): RenderedFootprint[]
```

Implementation:
1. If `children.length === 0`, return `[]`.
2. `ctx.save()` — snapshot all canvas state (preserves tile/hex render state)
3. `ctx.translate(view.pan.x, view.pan.y)` — align coordinate system with tile render
4. Set `ctx.lineWidth = _STROKE_WIDTH / view.zoom` — keep stroke at 1.5px regardless of zoom
5. For each child in `children`:
   a. Determine if placeholder: `child.parentAnchor === null || !parentMap.feetPerUnit`
      - If placeholder OR child has no way to compute real footprint, use 1×1 at anchor
        (if parentAnchor is null, skip the node entirely — cannot render without anchor)
   b. For real footprints: call `computeFootprint(childWidth, childHeight, childFPU, parentFPU, child.parentAnchor)`.
      BUT: `footprintOverlay.ts` does NOT have access to child map data (width/height/feetPerUnit).
      The caller (MapCanvas) passes `children` from `childrenOf()` — these are WorldSetNode objects,
      not TmjMap objects. The overlay MUST treat every child as a placeholder (1×1) because it cannot
      know child dimensions without fetching each child map. This is acceptable per CANVAS-03 —
      real footprint sizing requires the child map's width/height/feetPerUnit which MapCanvas will
      need to fetch separately. For Phase 6, use 1×1 footprint for all children unless the caller
      provides pre-computed rects. To support future expansion, accept an optional pre-computed
      footprint map parameter.

      **Revised signature:**
      ```typescript
      export function renderFootprintOverlay(
        ctx: CanvasRenderingContext2D,
        children: WorldSetNode[],
        parentMap: TmjMap,
        view: ViewState,
        hoveredMapName: string | null,
        /** Optional pre-computed footprints keyed by mapName. If not provided,
         *  children without parentAnchor are skipped; those with parentAnchor
         *  are rendered as 1×1 tile footprints (placeholder style). */
        footprintMap?: Map<string, Footprint>,
      ): RenderedFootprint[]
      ```

      For each child:
      - Skip if `child.parentAnchor === null` (cannot place without anchor)
      - Get footprint: if `footprintMap?.get(child.mapName)` exists, use it.
        Otherwise use `{ colMin: child.parentAnchor.col, colMax: child.parentAnchor.col, rowMin: child.parentAnchor.row, rowMax: child.parentAnchor.row }` (1×1 placeholder).
      - isPlaceholder = `!footprintMap?.has(child.mapName)` OR `!parentMap.feetPerUnit`
   c. Compute screen rect from footprint using `tileToScreen` (top-left corner) + tile size * zoom.
   d. Choose fill/stroke colors based on isPlaceholder and whether `child.mapName === hoveredMapName`.
   e. Set `ctx.setLineDash(isPlaceholder ? _WARN_DASH : _NORMAL_DASH)`.
   f. Draw filled rect: `ctx.fillStyle = fill; ctx.fillRect(x, y, w, h)`.
   g. Draw stroked rect: `ctx.strokeStyle = stroke; ctx.strokeRect(x, y, w, h)`.
   h. Draw label centered in rect:
      - Set `ctx.font = _LABEL_FONT`, `ctx.textAlign = 'center'`, `ctx.textBaseline = 'middle'`
      - Label text = isPlaceholder ? `'?'` : child.mapName
      - If `ctx.measureText(label).width > w - _LABEL_H_PAD * 2` and not placeholder:
        truncate with ellipsis: reduce chars until it fits, append `…`
      - Set shadow: `ctx.shadowColor = 'rgba(0,0,0,0.7)'`, `ctx.shadowBlur = 3`
      - Set `ctx.fillStyle = isPlaceholder ? _LABEL_COLOR_WARN : _LABEL_COLOR_NORMAL`
      - Draw at center: `ctx.fillText(label, x + w/2, y + h/2)`
      - Reset shadow: `ctx.shadowBlur = 0; ctx.shadowColor = 'transparent'`
   i. Collect RenderedFootprint: `{ mapName: child.mapName, screenX: x, screenY: y, screenW: w, screenH: h, isPlaceholder }`
6. `ctx.restore()` — restore canvas state
7. Return array of RenderedFootprint objects

**footprintAtPoint — hit-testing export:**
```typescript
/** Returns mapNames of all children whose screen rect contains (screenX, screenY). */
export function footprintAtPoint(
  screenX: number,
  screenY: number,
  rendered: RenderedFootprint[],
): string[]
```
Implementation: filter `rendered` where `screenX >= r.screenX && screenX <= r.screenX + r.screenW && screenY >= r.screenY && screenY <= r.screenY + r.screenH`, map to mapName, sort alphabetically.

Note on coordinate system: `renderFootprintOverlay` applies `ctx.translate(pan.x, pan.y)` which means the footprint screen positions (from `tileToScreen`) are relative to the translated canvas origin. The `RenderedFootprint.screenX/Y` values must be returned in the same canvas-space as pointer events (i.e., accounting for pan). Since `tileToScreen` returns `pan.x + col * tileW * zoom`, these are already in canvas-element coordinates — the translate in the draw code is redundant for the screen rect calculation. **Compute screen rect BEFORE the translate** using `tileToScreen` (which already includes pan), then apply translate only for ctx drawing operations. Return the `tileToScreen`-derived coordinates (which include pan) in RenderedFootprint so `footprintAtPoint` works directly against pointer event canvas coordinates.

**Revised drawing approach (no translate):**
Instead of `ctx.translate(view.pan.x, view.pan.y)`, compute all pixel coordinates using `tileToScreen` (which already includes pan) and draw directly. This avoids the coordinate double-counting issue.

The ctx.save/restore is still needed to preserve lineWidth, lineDash, font, textAlign, etc.
